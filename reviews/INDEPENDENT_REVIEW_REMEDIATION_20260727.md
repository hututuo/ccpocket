原实现的优点是：提交按行为拆分较清楚，跨 Bridge、协议、移动端状态与

## 兼容边界

- WebSocket 的新增限制只针对携带浏览器 `Origin` 的连接；无 `Origin`
  的既有原生客户端继续兼容。显式 API key 和显式 origin allowlist
  仍可跨主机名使用。
- Git 图片差异的 `requestId` 与 `projectPath` 都是加法字段；新 App
  面对旧 Bridge 时，只在同一 Bridge 上确实不存在歧义的情况下接受
  无标记旧响应。
- Side Chat 不再把“不知道”转换成 `on-request`，已知策略仍原样传递，
  未知策略交给官方 Codex 配置解析。
- Quick Look 调整只改变“文件已经在手机本地”后的预览决策，不放宽
  远程自动下载预算，也不改变 2 GiB 传输上限。
- Prompt History 没有格式或 schema 迁移；只把内存发布与持久化提交
  收束为同一个串行原子事务。
